# UCS fonts mirror

A preservation mirror of
Markus Kuhn's [Unicode fonts and tools for X11](https://www.cl.cam.ac.uk/~mgk25/ucs-fonts.html)
and its [text examples](https://www.cl.cam.ac.uk/~mgk25/ucs/examples/).
It keeps the original font archives and sample files available independently of the upstream server.

## Browse the mirror

[About the fonts](docs/index.md) |
[Font downloads and change log](docs/downloads/) |
[Text examples](docs/examples/)

Files are preserved byte-for-byte, including intentionally malformed UTF-8 test data.
The [SHA-256 manifest](docs/SHA256SUMS) records checksums and the UTC mirror time;
the [source inventory](docs/SOURCES.tsv) maps each file to its upstream URL.
